# 嵌入式基础与智能风扇综合项目

用户希望掌握电机、Wi-Fi、蓝牙等常用功能，并最终得到自动控制系统。采用独立stm32_control项目，保留原blink基线。当前会话直接实施，常规工程选择由助手处理。

综合对象：有持续热源的机箱，温度输入→STM32自动调节风扇→散热改变温度。目标35°C可调；AUTO/OFF/MANUAL；超温、传感器故障和电机堵转保护，按键急停。STM32配置ADC1 PA1、TIM2 CH1 PA0 1kHz PWM、PB13方向、PB14使能、PB12急停、PB0故障灯、USART1无线桥通信。模型仅验证功能数字行为与简化热/电机动态，不声称射频、电气或真实功率模型完整。

Renode执行实际STM32 HAL固件；ADC1需要聚焦本示例的功能补充模型，TIM2用官方模型；模拟对象读取实际PWM寄存器和输出使能，再反馈温度到ADC。报告记录控制、GPIO与串口，同时给出模型限制。正常收敛、设定值变化、手动/停机、传感器故障、超温、急停、电机堵转和错误接线必须有自动验收。

ESP32独立Arduino固件，UART2与STM32桥接；提供Wi-Fi SoftAP+HTTP和BLE GATT命令/状态。真实ESP32编译验证；电脑端检验相同UART协议，不能冒充真实Wi-Fi/BLE射频仿真。需要ESP32实体板验证无线连接。不会因Wokwi账户问题阻塞主路径。

基础练习分为GPIO/按键、ADC传感器、PWM电机、UART协议、自动控制与保护、Wi-Fi HTTP、BLE GATT，配参数修改、操作、可观察结果和验收命令。LCD/I2C/SPI/RTOS列为后续扩展，不宣称本次已经覆盖全部嵌入式功能。

工具复用stm32_bluepill/tools，所有新源码、制品、日志位于本项目对应目录。提供VS Code任务、GDB入口和离线图形结果页面。原始开发板资料不改动。
