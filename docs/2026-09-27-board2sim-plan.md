# Board2Sim 设计与执行计划

用户任务书是本项目的需求与执行授权；直接在当前工作区执行，不另设审批阶段。
这是新工作流的架构任务，范围以当前板卡 bring-up 为准。

## 设计
- 原始资料只读，完整清单、SHA256、重复组、解析状态及出处随报告交付。
- hardware_graph.json 保存真实 STC8H 硬件、电源、引脚、复用约束、未知项与证据。
- 原生路径复用本地 Keil C51 和提供的 STC 头文件；不刷写实体板。
- Wokwi 不支持 8051。采用用户允许的等效虚拟板策略：ATmega2560 执行移植的外设行为，独立适配层明确记录重映射。绝不将 AVR HEX 当成 STC 固件。
- SSD1306 仅为可选外接 OLED 的测试模型，真实控制器和地址 UNKNOWN；不由示例参数推定真实型号。
- Wokwi CLI 无 token 时实际执行并保留阻塞证据；本地 AVR8js 可验证移植固件的 CPU/GPIO/UART/I2C/ADC 行为，但不能把其结果归称 Wokwi 通过。
- 默认一键流程失败时退出非零，报告各阶段状态；允许明确指定 local 后端运行行为回归。

4. 实现扫描/验证/生成脚本，运行单元及故障注入测试。
5. 编译原生C51 bring-up和Mega行为固件，保留工具输出与HEX校验。
6. 执行Wokwi及本地行为回归，串口检查BOOT/TIMER/GPIO/ADC/I2C和真实按钮事件；测试不能仅相信固件打印的PASS。
